# proxy.i-xx.top

PAC 自动代理切换服务，支持在不同代理模式之间快速切换。

## 功能特性

- 🔄 三种代理模式切换：分流模式、全直连、全代理
- 📱 移动端适配：响应式设计，移动端合并面板
- 🌙 深色模式：支持自动跟随系统或手动切换
- 🔐 Token 认证：支持切换密钥保护
- 📋 一键复制：PAC 地址和固定模式地址快速复制
- 🔄 自动更新：支持从上游更新域名名单

## 代理模式

| 模式 | 说明 | PAC 文件 |
|------|------|----------|
| 分流模式 | 国内站点直连，海外站点走代理 | proxy.pac |
| 全直连 | 不使用任何代理，全部请求直接连接 | direct.pac |
| 全代理 | 所有请求都走代理，代理不通时直连 | global.pac |

## 快速开始

### 1. 配置代理服务器地址

访问网站后，在「PAC 信息」面板中设置代理服务器地址（如 `192.168.31.161:7890`）。

### 2. 客户端配置

在系统或浏览器的自动代理配置中填入：
```
https://proxy.i-xx.top/pac
```

### 3. 切换模式

访问网站，点击对应的模式卡片即可切换，切换后立即生效。

## 客户端配置指南

### Windows 10/11
1. 打开 **设置 → 网络和 Internet → 代理**
2. 打开「使用设置脚本」，脚本地址填 PAC URL
3. 点保存

### macOS
1. 打开 **系统设置 → 网络**，选中正在使用的网络
2. 点 **详细信息…** → **代理**
3. 勾选「自动代理配置」，URL 填 PAC URL
4. 点 **好**，再点 **应用**

### iPhone/iPad
1. 打开 **设置 → 无线局域网**，点当前 Wi-Fi 右边的 ⓘ
2. 拉到底部 **配置代理**，选「自动」
3. URL 填 PAC URL，点 **存储**

### Android
1. 打开 **设置 → WLAN**，长按当前网络 → **修改网络**
2. 展开 **高级选项**，把 **代理** 设为「自动」
3. PAC 网址填 PAC URL，保存

## 固定模式地址

如果需要固定某种模式、不受切换影响，可以直接使用以下地址：

- 国内直连，海外走代理：`https://proxy.i-xx.top/proxy.pac`
- 全部直连：`https://proxy.i-xx.top/direct.pac`
- 全部走代理：`https://proxy.i-xx.top/global.pac`
