客户端配置帮助

设备要和代理服务器 192.168.31.161 在同一局域网（192.168.31.x）；点开对应系统查看步骤。

Windows 10 / 11
  1. 打开 设置 → 网络和 Internet → 代理
  2. 打开「使用设置脚本」，脚本地址填 https://www.xiecailiao.vip/pac
  3. 点保存；同一页面上的「手动设置代理」保持关闭

旧系统可在「Internet 选项 → 连接 → 局域网设置」勾选「使用自动配置脚本」，填同一地址。Edge / Chrome 跟随系统设置，Firefox 默认也跟随。

macOS
  1. 打开 系统设置 → 网络，选中正在使用的 Wi-Fi 或以太网
  2. 点详细信息… → 代理
  3. 勾选「自动代理配置」，URL 填 https://www.xiecailiao.vip/pac
  4. 点好，再点应用

macOS 13 之前是「系统偏好设置 → 网络 → 高级 → 代理」。Safari、Chrome 跟随系统设置。

iPhone / iPad
  1. 打开 设置 → 无线局域网，点当前 Wi-Fi 右边的 ⓘ
  2. 拉到底部配置代理，选「自动」
  3. URL 填 https://www.xiecailiao.vip/pac，点存储

蜂窝网络不支持 PAC；换 Wi-Fi 或重连后可能需要在同一页面重新确认设置。

Android
  1. 打开 设置 → WLAN，长按（或点齿轮进入）当前网络 → 修改网络
  2. 展开高级选项，把代理设为「自动」
  3. PAC 网址填 https://www.xiecailiao.vip/pac，保存

部分机型只有「手动」选项，那就填主机名 192.168.31.161、端口 7890；也有部分 App（如 Android 版 Chrome）不读系统代理设置。

配好后用浏览器打开 https://www.xiecailiao.vip/ 即可随时切换模式；改完模式 Windows / macOS 通常几十秒内自动重新读取 PAC，想立刻生效就重启浏览器。

固定模式地址（备用）

需要固定某种模式、不受切换影响的设备，可以直接用下面这些地址。

  • /proxy.pac国内直连，海外走代理
  • /direct.pac全部直连
